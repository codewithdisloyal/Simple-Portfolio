# Code With Disloyal - Full Stack Developer Portfolio

![Project Banner](lonely-guy-retrowave-minimalist-uhdpaper.com-hd-6.422.jpg)

## 🚀 Overview

This is a modern, responsive personal portfolio website designed for a Full Stack Web Developer. The project features a sleek "Glassmorphism" aesthetic, interactive UI elements, and a clean, maintainable codebase.

## ✨ Features

- **Modern UI/UX**: clean design with glassmorphism effects (`glass-card` classes).
- **Responsive Layout**: Fully responsive design that works on mobile, tablet, and desktop.
- **Interactive Elements**: Hover effects, smooth scrolling, and dynamic content.
- **Sections**:
  - **Hero**: Introduction with animated text and code snippet visual.
  - **About**: detailed personal introduction and skills showcase.
  - **Services**: Grid layout of offered services.
  - **Portfolio**: Showcase of featured projects with hover overlays.
  - **Contact**: CTA section to encourage collaboration.
- **Dark/Light Theme Ready**: Structure supports theming (referenced in scripts).

## 🛠️ Technologies Used

- **HTML5**: Semantic markup.
- **CSS3**: Custom styling with variables, flexbox, and grid.
- **JavaScript**: Dynamic behavior and interactions.
- **FontAwesome**: For icons.
- **Google Fonts**: 'Inter' font family.

## 📂 Project Structure

- `index.html`: Main landing page.
- `style.css`: Main stylesheet containing all designs and animations.
- `js/`: Directory for JavaScript files (`theme.js`, `settings.js`, `search.js`).
- `blog.html`, `contact.html`, etc.: Additional pages for the site.

## 🚀 How to Run

1.  Clone the repository or download the source code.
2.  Open `index.html` in your web browser.
